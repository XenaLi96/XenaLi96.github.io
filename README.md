# Xi Li's personal website

Research, publications, news, and downloadable CVs.

Website: https://xenali96.github.io/

## Updating the site

- Edit `index.html` for biography, news, and publications.
- Edit `assets/css/style.css` for layout and styling.
- Replace the PDFs in `assets/cv/` to update the downloadable CVs.
- Commit and push to `main`. GitHub Pages publishes from the repository root.

This is a static, responsive website with no build dependencies. Preview locally with `python3 -m http.server 8000` and open http://localhost:8000/.
